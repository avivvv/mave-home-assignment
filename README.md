# mave-home-assignment
### DS Home Assignment: Building a Problem Resolution System for HPC Logs
#### Objective:
High performance computing (HPC) combines computing resources to achieve performance beyond a single computer, using either custom supercomputers or clusters of individual machines.
Your task is to build an intelligent system that not only analyzes HPC logs but creates an end-to-end workow for automated problem resolution. The goal is to reduce downtime by providing precise and actionable recommendations. The solution should be designed to handle evolving log formats and recommendations, making it "future-proof." While latency is not the primary concern, take into consideration that you want this to function in a real-world environment where cost and latency are important.
